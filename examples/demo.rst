代码块
======

.. code-block:: rust

   fn main() {
       let numbers: Vec<i32> = (1..=10).collect();
       for n in &numbers {
           if n % 2 == 0 {
               println!("{n} 是偶数");
           }
       }
   }

没有语言标注的字面块：

::

   $ mcat README.md
   $ mcat -n src/main.rs
